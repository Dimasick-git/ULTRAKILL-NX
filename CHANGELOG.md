# Изменения

## r33 — меню с тачем и полный NSP (локальный тест)

- Отдельный UI-указатель: нажатие, отпускание вне кнопки, drag ползунков/списков,
  отмена при потере фокуса. Координаты учитывают уменьшенный render texture FSR.
- Экранная клавиатура для InputField/TMP и панель SWITCH: рендер, FSR, RCAS,
  гироскоп/оси/чувствительность и FastLoad. Сохранение с проверкой записи и восстановлением config.bak.
- Настоящий resolver подсказок выбирает схему до keyboard composites, использует
  effectivePath и названия подключённого Switch-контроллера. Переназначения учитываются.
- Один полный NSP с RomFS, без зависимости от отдельной папки игровых ассетов.
  Saves, Preferences, config и il2cpp-кэш остаются на SD. Старый SD/NRO-запуск сохранён.
- Вложенные файлы SaltyNX копируются только при отсутствии, boot2.flag — последним;
  прерванная первая установка возобновляется. Ключи в комплект не включаются.
- Упаковщик проверяет NCA, PFS0/IVFC, NPDM-политику и SHA-256 каждого файла RomFS.
- Unity UI/GPU/input tests, host tests и ARM64/native build проходят. Новый NSP требует проверки на консоли.

## r32 — FSR-NX управление и FastLoad

- r31 аппаратно подтвердил подключение SaltyNX: session budget 1→9, mapped ABI=310.
- Добавлены совместимые FSR1/FSRC блоки: масштаб 25–100%, фильтр, резкость;
  кадр и applied сообщаются после вывода нового размера. Рендер остаётся GLES.
- Lite/NVN/HDR/FSRE не заявляются; расширенные поля нормализуются.
- Чтение refresh через SaltyNX, запрос 60 Гц при reported>60 в handheld,
  повторное чтение результата. Запросы FPS>60 ограничены поддержанными 60.
- Horizon FastLoad при старте и загрузке сцен, сброс до игры, 60-секундный
  timeout, HOME/focus/exit и отказ при недоступном worker. Частоты не задаются.
- Проверка на реальном устройстве для новых функций ещё нужна.

## r31 — повторное подключение SaltyNX

- По свежему r30: connect SaltySD rc=0x10801 до любого IPC; исключений мыши больше нет.
- Проверка реального SessionCount и ограниченный запрос +8 только при исчерпании
  небольшого бюджета процесса. Результаты и стадии подключения записываются в лог.
- Повтор соединения на present раз в секунду, максимум 30 попыток; после успеха
  или обнаружения чужого активного producer повторов нет.
- На карту записан официальный SaltyNX 2.1.3 с проверкой SHA и резервной копией.
  Нужна полная перезагрузка Atmosphere. Подключение на устройстве ещё не подтверждено.
- Расширены host-тесты: exhausted/available/denied budgets, deferred retry,
  timeout, optional absence и сохранение чужого producer. Native build PASS.

## r30 — исправление регрессии r29

- Убран override fixedDeltaTime: даже physics_hz 60 в старом конфиге игнорируется.
- Возвращён профиль FSR 540p → 720p; сохранены управление, GC и Umbra guard.
- Журнал точно указал на Mouse.current == NULL в GunControl.Update. При отсутствии
  мыши scroll=0, выполнение продолжается к gamepad-коду. Другие NRE не подавляются.
- Исправлен IPC-порт SaltyNX: SaltySD вместо InjectServ; запросы передают PID.
- Сборки NRO/IL2CPP и проверки mouse branch/IPC/telemetry/Umbra пройдены на ПК.
- Аппаратная проверка FPS и оверлея r30 ожидается; публичные PART пока r28.

## r29 (отозван после аппаратного теста) — локальный тест CPU/SaltyNX

- Прямой NX-FPS shared-memory bridge для NRO: реальные FPS/frametime, cap 15–60, optional service.
- Конфигурация physics_hz=0 (штатно) или 60–125; на тестовой карте 60 Гц и FSR 480p.
- На карте maxGore снижен с 256 до 64, личные настройки сохранены в резервной копии.
- Восстановление NULL-коллекций GunControl без создания оружия/дублирования слотов.
- Точные source sites NullCheck перед штатным исключением вместо вывода только кандидатов стека.
- Editor/Input/GPU и host telemetry tests PASS; IL2CPP 493 nodes, 0 failed.
- Прирост FPS и работоспособность моста на устройстве ещё не подтверждены.
- Публичный релиз пока r28, два прежних проверенных PART ZIP.

## r28 — переход в Лимбо и диагностика исключений

- По crash report: NULL после Umbra TomeLoader передавался в Tome::getStatus.
- LoadUmbraTome проверяет результат до getStatus; корректные Tome не меняются.
- Адреса выведены из совпадающих Unity symbols, код и BL-цели проверяются перед hook.
- Добавлены ограниченные образцы стека до выброса NRE; причина повторов пока неизвестна.
- IL2CPP: 9 nodes, 0 failed. Guard проверен на NULL, пустом входе и valid/invalid status.
- Повтор перехода 1-1 → 1-2 после исправления ещё нужен.

## r27 — журнал и комплект релиза

- Повторяющиеся одинаковые исключения: четыре первых образца, далее сводка раз в 5 с.
- Общий счётчик и новые ошибки сохраняются; источник NullReferenceException ещё не устранён.

## r26 — FSR1 и диагностика CPU

- EASU + RCAS из исходников AMD, shader bundle, вывод 540p в 720p, включая HUD.
- GPU-проверка в редакторе, активный вывод FSR подтверждён на Switch.
- Настоящие affinity/get/set и профиль CPU-потоков; dladdr сообщает базу модуля.
- Ограничен вывод чтений PlayerPrefs; при shader link error сохраняется GLSL.
- Стабильные 60 FPS и устранение оставшихся пауз пока не подтверждены.

## r25 — фактическое включение GC

- Исправлено значение режима: ENABLED=1; в r23/r24 значение 0 выключало GC.
- После включения проверяется disabled=0; несовместимый backend останавливает запуск.
- Аппаратные журналы r25/r26 подтверждают включённый GC и остановки потоков.

## r24 — кнопки меню Switch

- Подтверждение на физической A, отмена на B через роли Submit/Cancel.
- Позиционные привязки игровых действий и независимые оси курков сохранены.
- Названия четырёх лицевых кнопок виртуального устройства соответствуют Switch.
- Проверены настоящие UI actions игры, совместные нажатия и отпускание.
- Backend GC r23 сохранён. FSR на этом этапе ещё не был реализован (добавлен в r26).

## r23 — обновление для проверки issue #1

- Добавлен Horizon backend; режим GC по ошибке оставался выключен до r25.
- Реализованы остановка потоков Horizon и передача стеков/регистров в Boehm GC.
- Паузы GC согласованы с watchdog, добавлены показатели managed heap в журнал.
- Требуются согласованные NRO, IL2CPP и offsets. Проверки на ПК пройдены;
  повторные загрузки уровней на Switch ещё нужно проверить.
- Включено в оба полных ZIP r1; для существующих установок есть отдельное обновление.
