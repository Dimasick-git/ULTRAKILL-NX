# Изменения

## r24 — кнопки меню Switch

- Подтверждение на физической A, отмена на B через роли Submit/Cancel.
- Позиционные привязки игровых действий и независимые оси курков сохранены.
- Названия четырёх лицевых кнопок виртуального устройства соответствуют Switch.
- Проверены настоящие UI actions игры, совместные нажатия и отпускание.
- Backend GC r23 сохранён. FSR пока не включён; [план интеграции](docs/FSR.md).

## r23 — обновление для проверки issue #1

- Возвращена автоматическая сборка мусора вместо её отключения после старта.
- Реализованы остановка потоков Horizon и передача стеков/регистров в Boehm GC.
- Паузы GC согласованы с watchdog, добавлены показатели managed heap в журнал.
- Требуются согласованные NRO, IL2CPP и offsets. Проверки на ПК пройдены;
  повторные загрузки уровней на Switch ещё нужно проверить.
- Включено в оба полных ZIP r1; для существующих установок есть отдельное обновление.

## r1 — 18 октября 2026

Релиз обновлён до внутренней сборки r24. Проверка исправления перезапусков на консоли продолжается.

- Запуск с HOME через собственный форвардер.
- Управление геймпадом и гироскопом; исправлена инверсия обеих осей.
- Потоковое видео: JPEG декодируется в отдельном потоке, звук идёт через Unity.
- Курки больше не генерируют дополнительные нажатия крестовины.
- Исправлен вылет диагностики при чтении адреса перед началом модуля.
- Убраны периодические остановки потоков для снимков во время нормальной игры.
- Исправлено время движка; физика использует штатный шаг FixedUpdate.
- Добавлены показатели реального FPS, времени кадра и ожидания представления.
- Включены рендер 540p, меньшие текстуры, ограниченный кэш шейдеров и сниженный gore.

Проверены запуск, обучение, видео и переход к 0-2. Полное прохождение и работа
на разных моделях Switch ещё требуют тестирования.
