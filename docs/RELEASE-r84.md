# r84 / TEST48 — настройки и перевод

Установка одним `ULTRAKILL-NX_r84_FULL.nsp` через DBI, затем запуск с HOME.
Данные игры и все таблицы находятся внутри установленного приложения.

- **Настройки → Общие → Language:** смена языка с немедленным применением.
- **Настройки → Управление → Gyroscope:** включение, чувствительность, инверсия X/Y.
- Английский по умолчанию; выбранный язык сохраняется.
- Исправлены выбор скрытого меню и загрузка неверного встроенного шрифта.
- Добавлены переводы пропущенных названий параметров и вариантов в верхнем регистре.

`SD_LANG_r84.zip` нужен для обновления внешних таблиц. Если на SD остались
старые `switch/ultrakill/lang/*.tsv`, они заменяют только совпадающие строки,
а новые строки берутся из NSP. ZIP обновляет сами SD-переводы. Сохранения
и конфигурацию не удаляй.

Проверки интерфейса и сборки на ПК выполнены. Нужны проверка меню и гироскопа
на Switch, переход уровня и обычный бой. Новые гарантии FPS не заявляются.
Переводы 12 языков остаются машинными черновиками с частичной вычиткой.
