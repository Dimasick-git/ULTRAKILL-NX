# ULTRAKILL — NX 2.0.0 / установка и обновление

Один `ULTRAKILL-NX_2.0.0_FULL.nsp` устанавливается через DBI. Внутри находятся
загрузчик, библиотеки Unity/IL2CPP, уровни, текстуры, звук, ролики и FSR.
Игровые данные читаются из RomFS установленного приложения. Отдельно
распаковывать `switch/ultrakill` для этого способа запуска не требуется.

Установи NSP через DBI и запусти ULTRAKILL — NX с HOME. Title ID сохранён:
`01005CE3B1A40000`. Полный NSP заменяет прежний форвардер этого проекта.
Существующие сохранения, Preferences и `config.txt` остаются в
`sdmc:/switch/ultrakill`. Туда же игра пишет журнал и служебный кэш.
Не удаляй эту папку целиком при переходе с ZIP-сборки.

## Скачать полный файл

На странице релиза будет ссылка **«Скачать полный NSP»** на облачное хранилище.
Скачай `ULTRAKILL-NX_2.0.0_FULL.nsp` целиком и установи его через DBI.
Распаковка, склейка и отдельные файлы игровых данных не требуются.
SHA-256 установщика будет указан в описании релиза.

## Сенсорный экран и настройки

Меню, настройки и терминалы принимают касания. Ползунки и списки можно
перетаскивать пальцем. Для обычных и TMP-полей ввода появляется экранная
клавиатура: APPLY завершает ввод, CANCEL возвращает исходное значение.
В бою используются контроллеры и гироскоп; экранных боевых кнопок нет.

Язык выбирается в «Общих», гироскоп и чувствительность — в «Управлении».
В разделе Video находится категория Render: высота рендера 180–720,
апскейлер OFF / FSR 1, резкость, ускорение CPU на загрузках и подготовка
шейдеров врагов. Гироскоп, его чувствительность и инверсия осей находятся
в Controls; язык — в General / Language. Используются штатные строки,
списки и ползунки игры. Отдельного меню SWITCH и экспериментальных FSR 3 /
генерации кадров нет. Старые экспериментальные настройки сбрасываются
при запуске. Параметры сохраняются на SD после короткой паузы. Режим
FastLoad действует только на загрузках; разгон памяти не применяется.

Подсказки используют действующие привязки контроллера. По умолчанию прыжок
показывает B, движение — LS, триггеры — ZL/ZR. A подтверждает выбор в меню,
B возвращает назад. Переназначение действия меняет его подсказку.

## SaltyNX

В NSP также вложены официальные файлы SaltyNX 2.1.3 и поддержка SaltySD.
При первом запуске на новой карте загрузчик копирует недостающие файлы.
Существующий системный модуль и пользовательские файлы не заменяются.
После первой установки SaltyNX полностью перезагрузи консоль в Atmosphère:
установленный системный модуль запускается при загрузке системы.
Сбой копирования не активирует незавершённую установку; следующий запуск
продолжает её по оставленному маркеру. Файлы проверяются по SHA-256.

## Проверка сборки

В r93 язык выбирается в общих настройках; гироскоп и чувствительность —
в разделе управления. Английский выбран по умолчанию. Таблицы и шрифт CJK находятся внутри
NSP. Если раньше копировался перевод на SD, файл
`switch/ultrakill/lang/<код>.tsv` заменяет только совпавшие строки. Новые
встроенные строки доступны и со старым SD-файлом; сам файл можно обновить
из отдельно подготовленной SD-таблицы. Для новой установки это не требуется. Подробности
и состояние переводов — в [LOCALIZATION.md](LOCALIZATION.md).

Упаковщик повторно открывает NSP, проверяет хеши NCA, таблицы PFS0/IVFC,
загрузчик и каждый файл RomFS по внутреннему манифесту. Отчёт лежит рядом
с NSP в файле `.verified.json`. Ключи используются только локально и не
включаются ни в NSP, ни в репозиторий.

Проверки на ПК не заменяют запуск на консоли. Для проверки после установки:
открыть настройки касанием, потянуть ползунок и список, изменить параметр
и проверить его после перезапуска; затем проверить подсказки в обучении
и переход между уровнями. Стабильные 60 FPS этим изменением не заявляются.
