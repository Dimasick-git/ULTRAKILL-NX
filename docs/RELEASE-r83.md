# ULTRAKILL — NX · r83 / TEST47

Локальная тестовая сборка от **Dimasick-git**. Главный тестер, скриншоты и видео —
**Ryazhenka-helper-01 / Zeropaxy**.

## Языки

Переключатель в панели **SWITCH**: English, Русский, Українська, Deutsch,
Français, Español, Português (Brasil), Italiano, Polski, Türkçe, 日本語,
한국어, 简体中文, 繁體中文 и «Авто» по языку системы.

Русские порции 000–048 объединены; таблица для SD пересобрана. Остальные
12 переводов дополнены машинным переводом с терминологическими словарями
и частичной вычиткой. Проверка структуры автоматизирована; полная проверка
носителями языка и тест длинных строк на консоли ещё нужны.

Включён шрифт NxCjk на основе Noto Sans CJK (SIL OFL 1.1). Исправлено применение
шрифта к названиям языков, которые уже записаны на родном языке.

## Файлы для проверки

- `ULTRAKILL-NX_r83_FULL.nsp` — один полный установщик для DBI, включая игровые
  данные, таблицы языков и шрифт. Запуск с HOME.
- `SD_LANG_r83.zip` — только таблицы языков для существующей SD-установки.
  Полный NSP уже содержит эти таблицы.
- `ULTRAKILL-NX_r83_FULL.verified.json` — отчёт проверки установщика.

Сохранения и настройки остаются на SD. Внешние таблицы в
`switch/ultrakill/lang/` имеют приоритет: старый файл может скрыть обновлённый
перевод внутри NSP. Замени его из языкового ZIP или убери старую подмену.

## Изменения относительно r32

Сборка включает накопленные изменения GC, физики, распределения потоков CPU,
кэшей и адаптивного показа кадров, исправления переходов и выхода из игры.
Подробности и условия прежних замеров — в [CHANGELOG](../CHANGELOG.md).
Языковое обновление не является новым подтверждением производительности.

## Что проверить на Switch

1. Запуск установленного NSP, звук и загрузку сохранения.
2. Смену языка в панели SWITCH и сохранение выбора после перезапуска.
3. Калибровку звука, подтверждения в меню и терминале, длинные описания.
4. Японские, корейские и китайские символы, отсутствие квадратов и обрезанных строк.
5. Переход уровня и тяжёлый бой на прежних настройках.

Проверки NCA, IVFC и файлов RomFS на ПК не заменяют этот запуск.
Полное прохождение и стабильные 60 FPS во всей игре не подтверждены.

Исходный репозиторий содержит код порта, переводы и инструменты; оригинальные
данные игры, ключи и SDK в него не входят. GitHub в рамках этой подготовки
не обновляется: публикация будет отдельным действием после проверки.
