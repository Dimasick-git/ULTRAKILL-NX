# Правовая информация

ULTRAKILL — NX — неофициальный homebrew-порт для Nintendo Switch. Проект не связан с Nintendo, New Blood Interactive, Arsi “Hakita” Patala или Valve.

Название ULTRAKILL, сама игра, её код, ассеты, музыка, видео и библиотеки принадлежат правообладателям. Этот репозиторий не заявляет на них прав.

В Git находятся код порта, загрузчик, forwarder, инструменты и документация. Реверс-инженерный код игры, Unity-проект, консольные ключи и игровые данные в репозитории не хранятся.

Релизные архивы могут содержать файлы, необходимые для запуска игры. Эти файлы не входят в лицензии исходников порта и распространяются на условиях, определённых для конкретного релиза.
