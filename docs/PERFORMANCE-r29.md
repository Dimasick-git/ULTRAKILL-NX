# r29: локальный профиль для тяжёлых боёв

Пользователь подтвердил прохождение перехода Лимбо с r28 без зависания.
В его журнале есть боевые интервалы 10.7–15 FPS, max frame до 280 мс,
потоки UnityMain около 70–90% одного ядра и два Job.Worker.
Это подтверждает тяжёлую нагрузку CPU, но не является измерением GPU busy.

## Изменения для проверки

- На тестовой карте физика 60 Гц вместо project timestep 0.008 с (125 Гц).
  Параметр `physics_hz 60` задаёт настоящий Time.fixedDeltaTime один раз через
  штатный icall Unity. wall clock, timeScale и managed deltaTime не подменяются.
  Скриптовые изменения fixedDeltaTime, например в ролике, сохраняются.
  `physics_hz 0` оставляет шаг проекта; поддержаны значения 60–125.
- FSR получает 480p вместо 540p: примерно на 21% меньше внутренних пикселей.
  Это уменьшает пиксельную работу, но не гарантирует такого же прироста FPS.
- На карте тестируется maxGore=64 вместо 256, с резервной копией личных настроек.
  Обновление core не раздаёт пользовательский LocalPrefs.
- Восстановление NULL-коллекций GunControl при загрузке сцены повторяет
  инварианты исходного конструктора. Существующие оружие и списки сохраняются;
  пустой внешний список оставляется для штатного Start. В журнале есть число
  фактических repairs: наличие исправления кода ещё не доказывает устранение NRE.
- Ограниченные `[nullcheck] source=...cpp:line` фиксируют точную точку NULL
  перед штатным исключением. Обычный non-null путь callback не вызывает.
- [Прямой мост NX-FPS/SaltyNX](SALTYNX.md) для настоящих времён кадров NRO.

## Проверки

Editor: реальный тип GunControl, восстановление NULL, сохранение существующих
ссылок оружия, отсутствие дубликатов и повторный вызов; Input System и оригинальные
UI actions A/B; GPU EASU/RCAS. Host: настоящий код статистики и pacing SaltyNX.
Проверки на Switch ещё нужны; стабильные 60 FPS не заявляются.

Повторить тот же бой при одинаковых частотах и маршруте. Для разделения причин:
сначала physics_hz=0/540p, затем 60/540p, затем 60/480p. Сравнить frame/p95/max,
CPU, draws и память. Отдельно проверить прыжки, рывок, столкновения, оружие,
замедление времени, ролики и перезапуск сцены. Тест physics 60 требует этой
проверки поведения: численный шаг симуляции действительно меняется.

Откат профиля: `physics_hz 0`, `render_height 540`, вернуть прежний LocalPrefs
или maxGore=256 в настройках. Библиотеку, offsets и ОБЕ metadata откатывать вместе.
