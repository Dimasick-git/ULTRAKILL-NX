# Локализация r93

Язык меняется в **Настройки → Общие → Language** через штатный выпадающий
список игры. System использует язык системы. По умолчанию выбран English.
В списке используются названия латиницей, чтобы они читались до загрузки
шрифта выбранного языка. Кириллица и CJK в самой игре используют запасные шрифты.
Выбор сохраняется в `ui_language`. Гироскоп, его отключение, чувствительность
и инверсия осей находятся в **Настройки → Управление → Gyroscope**.

Новые переводы подготовлены с Google Translate, локальными моделями
[Argos Translate](https://github.com/argosopentech/argospm-index), словарями терминов и проверкой
разметки. Носители языка ещё не вычитали их целиком. Длинные справки, склонение
терминов и переносы в узких кнопках требуют проверки на консоли.
Имена авторов, названия произведений, клавиши и технические сообщения могут
сохраняться на английском. Наличие всех выбранных ID не означает перевод
каждого возможного динамического текста игры.

## Обновление на SD

В полном NSP таблицы уже находятся в `assets/NxPort/lang/`. Дополнительная
установка языкового пакета не требуется. В r84 встроенная таблица загружается первой. Файл на SD
`switch/ultrakill/lang/<код>.tsv` заменяет только присутствующие в нём строки;
новые встроенные строки сохраняются даже со старым SD-файлом. Для обновления
самих SD-переводов используй `SD_LANG_r93.zip` и перезапусти игру.

## Подготовка таблиц

Исходные английские тексты извлекаются локально; в Git находятся только
словари `loc/<код>.json` с хешами и переводами. Хеш — FNV-1a 64 по UTF-16.
Нумерованные рабочие порции и английские выгрузки в публикацию не входят.

```sh
python tools/loc_chunks.py check --source source.json --chunks chunks --loc work/de --reference work/ru
python tools/loc_chunks.py merge --loc work/de -o loc/de.json
python tools/build_lang.py --source source.json --loc loc --out lang
python tools/test_localization.py
```

`check` проверяет обязательные ID, теги, подстановки и управляющие маркеры;
при ошибке возвращает ненулевой код. `merge` объединяет только `NNN.json`,
отвергает дубликаты и не включает `glossary.json`. TSV экранирует табуляцию,
переносы и обратную косую черту. Отсутствующая строка остаётся на английском.

## Шрифт CJK

Используется статический экземпляр Noto Sans CJK, переименованный в NxCjk,
с лицензией SIL OFL 1.1. Источник и лицензия:
[Noto CJK](https://github.com/notofonts/noto-cjk/tree/main/Sans),
[SIL OFL](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE).

Установи `fonttools`, скачай upstream `NotoSansCJKjp-VF.ttf` и подготовь:

```sh
python tools/prepare_loc_font.py --input NotoSansCJKjp-VF.ttf --output PROJECT/Assets/NxPortFonts/NxCjk.ttf
```

Скопируй `NxFontBuild.cs` в редакторские скрипты проекта и вызови Unity
`-batchmode -quit -projectPath PROJECT -executeMethod NxFontBuild.Export`.
Полученный Android-бандл `Build/NxPortFontsAndroid/nx_fonts.bundle` кладётся
в `assets/NxPort/`, лицензия — в `licenses/NotoSansCJK-OFL.txt`.
Бандл загружается только при выборе японского, корейского или китайского.
